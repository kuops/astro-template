这是一篇**标题里带 `</script>`** 的测试文章（C05 场景）。

文章标题会进入全站布局的 ld+json 结构化数据。若序列化结果未转义 `<`，标题中的
`</script>` 会提前终止 JSON-LD 脚本块，后续内容会被当作正文渲染（潜在注入面）。

修复后，结构化数据序列化时将 `<` 转义为 `\u003c`，脚本块保持完整。验证方法：
在构建产物的该文章 HTML 中搜索 `application/ld+json`，其 JSON 内不应出现未转义的
`</script>`，且应能看到 `\u003c` 形态的转义输出。
